# Work365

Work365 is a personal productivity suite built with React. It brings a collection of useful everyday tools into one simple and convenient workspace.

### Apps

* **Calculator** — Perform quick and simple calculations.
* **JSON Formatter** — Format and validate JSON data.
* **QR Generator** — Generate QR codes from text, links, and other data.
* **Password Generator** — Create strong and secure passwords.
* **Unit Converter** — Convert values between different units.
* **Notes** — Create and manage personal notes.
* **Todo** — Organize tasks and manage your daily to-do list.
* **Color Picker** — Pick colors and get their color values.
* **Markdown Editor** — Write and preview Markdown content.
* **PDF Tools** — Useful tools for working with PDF files.
